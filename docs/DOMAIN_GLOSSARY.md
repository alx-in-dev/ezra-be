# Словарь предметной области

Игровая терминология Ezra встречается везде в коде — в именах пакетов,
обработчиков, колонках БД, типах asynq-задач. Эта страница переводит её на
простой инженерный язык, чтобы остальная документация (и код) читались
естественно. Составлено по `internal/canon/` и `model.go` каждого пакета, а
не по старым дизайн-докам/лору — так что должно соответствовать тому, что
реально работает.

## Карта и мир

- **Cell (клетка)** — фиксированный тайл сетки карты реального мира
  (`internal/cell`), с ключом `"{lat}_{lng}"`, за которым стоит точка PostGIS
  (`geom`). Атомарная единица, к которой привязано всё остальное (башни,
  разломы, заражение). Клетки создаются лениво — при первом запросе игрока
  `/map/cells` в новый регион ~0.1°×0.1° сервер запрашивает Overpass API
  (OpenStreetMap), чтобы засеять флаги местности (`has_nearby_building`,
  `has_nearby_road`) для этой области.
- **Infection (заражение)** — значение порчи клетки (0–100), пересчитывается
  плановым воркером (`internal/infection`, каждые 5 минут) на основе соседних
  разломов, ульев, башен и соседних клеток. Переход через порог может
  заспавнить разлом.
- **Rift (разлом)** (`internal/rift`) — враждебная точка спавна на карте.
  Имеет тир (`minor` / `medium` / `critical`), интенсивность и число духов;
  расширяется каждый час, органически спавнится каждые 10 минут, закрывается
  победой в бою против него.
- **Hive (улей)** (`internal/hive`) — симбионтский аналог Core игрока: корень
  региона заражения. Пульсирует заражением в своём радиусе и ежечасно сеет
  разломы.

## Игровые постройки и сеть

- **Tower (башня, в комментариях/UI часто "маяк"/beacon)** — постройка игрока
  (`internal/tower`), стоящая на своих lat/lng, привязанная к клетке для
  учёта заражения. Имеет HP, уровень, стоимость содержания и проецирует
  радиус подавления, который борется с заражением поблизости. Ежечасно
  приносит пассивный доход и получает ежечасный урон "давлением" от заражения
  вокруг.
- **Core / Network (сеть)** (`internal/network`) — личный корневой узел игрока
  (`Core`) и граф рёбер `Link`, соединяющих его с башнями. У Core есть бюджет
  энергоёмкости ("Ecap"), который должен покрывать сумму содержания всех
  башен плюс стоимость всех линков; линк стоит `ceil(length_m / 100) * 3`.
- **Station (станция)** (`internal/station`) — построенная игроком
  электростанция, повышающая локальную ёмкость под башни в областях с
  разреженной сеткой OSM. Имеет свой жизненный цикл
  active → degrading → ruins (тики раз в 6ч), если её не обслуживать.
- **Legacy network (легаси-сеть)** (`internal/legacy`) — что происходит с
  человеческими башнями/Core игрока после перехода на сторону симбионтов:
  вместо исчезновения они деградируют `legacy_stable → legacy_fading →
  legacy_offline` за 24–48 часов (ежечасный воркер), если рядом их не
  поддерживает другой активный игрок-человек.
- **City Link** (`internal/citylink`) — добровольный союз взаимопомощи между
  двумя игроками: они могут чинить башни друг друга и видеть чужие алерты
  обороны. Без слияния ресурсов/сети — чисто кооперативная механика.
- **Spire** (`internal/spire`) — крупная региональная эндгейм-постройка,
  которую игроки совместно финансируют (фрагментами + вкладом ресурсов) и
  поддерживают; даёт бонус к подавлению заражения на весь свой радиус. Тики
  жизненного цикла раз в 6 часов.

## Фракции и PvP

- **Faction (фракция)** (`internal/faction`) — игрок либо `human`, либо
  `symbiont`. Сначала игроки "контактируют" с противоположной стороной, потом
  явно "выбирают"; смена стороны имеет кулдаун 24ч и лишает легаси-дохода в
  пользу того, кого игрок покинул.
- **FactionWar** (`internal/factionwar`) — сезонное соревнование фракций со
  счётом (закрытие разломов, коллапс ульев, перегрузка башен, пробитие
  куполов — всё даёт очки), подводится раз в день воркером.
- **PvP / Dome Breach (пробитие купола)** (`internal/pvp`) — симбионт может
  разведать и "пробить" защитный купол вражеского игрока, принудительно
  подняв заражение на этой клетке и открыв под ней разлом.
- **Capture (захват)** (`internal/capture`) — захват вражеской башни:
  `lockpick` (скрытно, без боя) или `force` (запускает бой за неё).

## Мета-прогрессия симбионта

- **Symbiont** (`internal/symbiont`) — гео-геймплей фракции симбионтов:
  нахождение под куполом враждебного игрока-человека медленно тянет энергию
  симбионта (плановый "drain tick" раз в 2 минуты), ослабевая по мере того,
  как симбионт поднимает заражение клетки обратно, выгрызая свой карман.
- **Resonance** (`internal/resonance`) — трек мета-прогрессии симбионта:
  Resonance Level (RL1–RL5) открывает больше "слотов управления сущностями".
- **Roster / Entity** (`internal/roster`) — Resonance Pool материализует
  небольшое число автономных **сущностей** (архетипы: `assault`,
  `distortion`, `scout`, `absorber`), которых игрок назначает на враждебную
  башню или разлом; каждая тикает по своему серверному таймеру через
  конечный автомат `manifesting → assigned → recovering` (тик раз в 10 минут).

## Армия и бой

- **Unit (юнит)** (`internal/unit`) — отдельный член армии (тип, уровень, XP,
  HP, ATK); деградирует, если долго простаивает без дела (воркер раз в 6ч).
- **Squad (отряд)** (`internal/squad`) — именованная группа юнитов, отправленная
  на миссию (patrol / attack); миссии завершаются воркером раз в минуту.
- **Battle (бой)** (`internal/battle`) — пошаговое разрешение боя против
  разлома или улья. Есть рискованное действие-рывок "overcharge" (×2.5 урона
  наносимого, ×1.15 получаемого, 25% шанс осечки), доступное начиная с
  release stage v1.0.
- **Survivor** (`internal/survivor`) — вербуемый NPC, спавнящийся рядом с
  игроком, которого можно превратить в юнита.
- **Pet (питомец)** (`internal/pet`) — компаньон, которого можно отправить на
  задачи поиска/патруля; результат забирается автоматически воркером раз в
  минуту.

## Прогрессия и мета

- **Player (игрок)** (`internal/player`) — аккаунт: уровень/XP, ресурсы
  `energy` + `materials`, лимит армии, очки навыков (ветки defender /
  commander / energist), последняя известная GPS-позиция (используется для
  проверки скорости в античите — см.
  [ARCHITECTURE.md](ARCHITECTURE.md#античит)), состояние онбординга.
- **Achievement (достижение)** (`internal/achievement`) — разблокировки,
  вычисляемые прямо из существующих таблиц (число башен, уровень Core,
  побед в боях, собранных спектров, уровень игрока) — отдельной системы
  учёта статистики нет.
- **Bestiary (бестиарий)** (`internal/bestiary`) — коллекционный каталог
  открытых игроком типов врагов, тиров разломов, типов башен и спектров
  резонанса.
- **Item (предмет)** (`internal/item`) — стеки инвентаря; резонансные
  "сигнатуры" используют поле `Variant`, чтобы записать, к какому спектру они
  относятся (коллекционный набор для эндгейма).
- **Quest (квест)** (`internal/quest`) — ежедневные квесты плюс чек-ин за
  стрик входов.
- **Shop (магазин)** (`internal/shop`) — IAP-каталог: покупки кристаллов и
  подписки, с воркером раз в 24ч, истекающим просроченные подписки.

## Гейтинг по релизам

`internal/canon.CurrentReleaseStage` закрепляет весь бэкенд за одной из
стадий `mvp → v1.0 → v1.1`. Некоторые фичи объявляют минимальную стадию
(например, overcharge в бою и уровни башен 4–5 требуют `v1.0`;
`tower_pressure` требует `v1.1`), и `canon.IsFeatureAvailable(feature)`
гейтит их централизованно, вместо того чтобы каждый пакет реализовывал
проверку у себя.
